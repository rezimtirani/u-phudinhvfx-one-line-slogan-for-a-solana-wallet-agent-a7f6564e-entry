One slogan for a Solana wallet agent, seventeen words on a single line: Solana speed with agent brains — a wallet that reads the market, signs the smart moves, and guards every lamport.

> Solana speed, agent brains: your wallet reads the market, signs the smart moves, and guards every lamport.

## How it works

`main.py` (Python 3 standard library only) writes the slogan to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: at most twenty words of UTF-8 text, a single line.

```sh
python3 main.py
```
